要点（3行で）

  • ホンダは2026年11月26日、米国生産の「Acura INTEGRA Type S」を12月18日に日本で発売すると発表した。販売は250台限定。
  • 価格は899万8,000円（税込）の1グレード。2.0L VTEC TURBOに6速MT、FFの4人乗り。
  • 250台のうち30台は抽選販売で、応募は2027年1月8日まで。残る220台は販売会社に直接問い合わせる形になる。

この記事は、本田技研工業のニュースリリースと、Honda公式サイトの抽選販売ページに書かれている内容だけで作っています。公式資料に書かれていない項目は「記載なし」としました。

何が発表されたのか

Acura（アキュラ）は、1986年に設立されたホンダのブランドです。INTEGRA Type Sは、そのAcuraのスポーツモデルで、米国オハイオ州のメアリズビル四輪車生産工場で作られています。リリースによると、北米では2023年の発売以来、高い評価を受けてきたモデルです。

今回の日本導入には、国土交通省が2026年2月に作った「米国製乗用車に関する認定制度」が使われます。米国向けの仕様のまま輸入できる制度で、一部の装備は米国の基準に合わせた仕様になっています。ホンダは同じ制度で、大型SUV「PASSPORT TRAILSPORT ELITE」も発売する予定だとしています。

米国向け仕様のまま入ってくる限定車なので、通常のホンダ車とは買い方も仕様の確認ポイントも違います。以下で順に整理します。

出力とトルクは、米国の現地カタログの数字を日本で一般的な単位に換算した参考値だと注記されています。日本の型式指定の数字ではないので、ほかの国産車の諸元表と並べるときは、この点に気をつけてください。

ハンドル位置はリリースに書かれていませんでした。米国向け仕様での導入なので、購入を考えている人は販売会社で確認しておくと安心です。

装備では、ヘッドアップディスプレー、16スピーカーのプレミアムオーディオ「ELS 3D STUDIO」、ヒーター付きの運転席パワーシートが挙げられています。安全装備は「AcuraWatch」が標準で、衝突軽減ブレーキ、路外逸脱抑制、ACC、LKAS、オートハイビーム、後退出庫サポート、近距離衝突軽減ブレーキ、パーキングセンサー、標識認識の9機能です。

注意したいのは標識認識機能です。米国仕様のデータで動くため、日本の標識を正しく認識できないことがある、とリリースに注意書きがあります。

買い方：抽選30台と販売会社220台

250台は、買い方が2つに分かれています。

抽選の日程は次のとおりです。抽選で当たるのは「商談する権利」で、当選しても購入が約束されるわけではありません。販売店との商談を経て契約が成立します。

内容日程
応募期間2026年11月26日（木）〜2027年1月8日（金）
当選の連絡2027年1月18日（月）から順次メール
繰り上げ当選の案内2027年1月19日（火）〜1月26日（火）（辞退が出た場合）
商談期間事務局が商談の意思を確認した日から2週間

応募は1人1回・1台までで、自分が所有者か使用者になること、車庫証明を取れること、転売目的でないことなどが条件です。ボディカラーは第1・第2希望を出して抽選し、当選時に決まります。後から色は変えられません。商談は原則として応募時に選んだ販売店で行い、店の変更もできません。

抽選についての問い合わせは専用の事務局が受け付けていて、Honda販売店では受け付けていない点にも注意してください。当選発表は1月中旬ごろにライブ配信で行う予定とされています。

シビック TYPE Rとの比較

リリースでは、INTEGRA Type SはCIVIC TYPE Rとプラットフォームやパワートレインを共有するモデルだと説明されています。ただし性格は違い、サーキット志向のTYPE Rに対して、INTEGRA Type Sは街乗りでの加速感やサウンドを重視した車と位置づけられています。

出力の数字は単位の換算元が違うため、4kWの差をそのまま性能差と読むのは避けたほうがよいでしょう。シビック TYPE Rの価格は、今回確認した公式ページで読み取れなかったので表に載せていません。

数字の上では、エンジン・トランスミッション・駆動方式・定員はほぼ同じです。選ぶ基準は、限定車であることや装備の違い（ヘッドアップディスプレーや16スピーカーのオーディオなど）、そして街乗り寄りかサーキット寄りかという性格の違いになりそうです。

こんな人に向いている

  • 6速MTのスポーツモデルを、普段使いもしながら楽しみたい人：ホンダ自身が、TYPE Rよりストリート向けの車だと説明しています。
  • 人と違う車に乗りたい人：日本での販売は250台限定です。
  • 装備の充実を重視する人：HUDやプレミアムオーディオ、パワーシートが付いています。

反対に、サーキット走行が中心の人や、ボディサイズ・燃費などを細かく比べてから決めたい人には向きにくいかもしれません。日本向けの詳しい諸元は、リリースの時点では公開されていません。標識認識のように日本の環境に合わない機能がある点も、納得したうえで選びたいところです。
